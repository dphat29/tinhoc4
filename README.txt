BẾP NHÀ VIỆT — BẢN ẢNH THẬT

1. Upload index.html, style.css, script.js, .nojekyll và thư mục images lên root repo GitHub.
2. GitHub Pages: Settings > Pages > Deploy from a branch > main > /(root).
3. Mở site bằng HTTPS để ảnh thật được tải từ Wikimedia Commons API.
4. Lần đầu mở từng món cần Internet; ảnh được cache trong trình duyệt.
5. Ảnh được truy vấn theo đúng tên món, không phải ảnh minh họa SVG. Kiểm tra nguồn/giấy phép từng ảnh trên Wikimedia Commons trước khi dùng cho sản phẩm công khai thương mại.
